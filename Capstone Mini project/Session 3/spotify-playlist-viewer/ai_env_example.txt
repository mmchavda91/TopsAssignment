KEY SECURITY RULES (ChatGPT Suggested):
================================================

1. NEXT_PUBLIC_ prefix  = Safe for browser (client-side)
   No prefix           = Server-side only (PRIVATE — never sent to browser)

2. Add .env.local to .gitignore to prevent accidental commits

3. Use .env.example file with placeholder values for team sharing

4. Rotate API keys regularly on production

5. Use Firebase App Check to prevent API abuse
